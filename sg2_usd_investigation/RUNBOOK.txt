SG2 별도 조사/검증 파일 사용법

먼저 REPORT.ko.txt의 적용 범위를 읽으세요. 공식 source/ 파일을 수정하는 단계는 없습니다.
review/의 Python 파일은 원문 아래 주석 비교용입니다. 이 파일 자체를 실행하면 제안이 적용되지 않습니다.
runtime/FFW_SG2_trial.py의 make_trial_cfg()는 별도 Isaac Lab 환경에서만 사용할 cfg factory입니다.
runtime/mobile_actions.py는 별도 모바일 task용 행동 factory입니다. 원본 task에 자동 설치되지 않습니다.

최종 모델:
  runtime/FFW_SG2_trial.usd                  물리 검증을 통과한 로봇 사본
  runtime/FFW_SG2_with_sensors.usda           위 로봇 + 머리 카메라2/손목 카메라2/LiDAR2의 동적 layer
  runtime/FFW_SG2_v4_source.usd               이전 조사 v4의 보존 사본 (수정 전)

주의: results/**/runtime/sensor_scene.usda는 거리 시험을 위한 정지 fixture입니다.
주행 모델 대신 사용하지 마세요. 동적 센서 모델은 runtime/FFW_SG2_with_sensors.usda입니다.
단순 USD 로드만으로 모터 cfg나 sensor annotator가 자동 연결되지는 않습니다.

Isaac Sim이 이미 켜져 있을 때 (기존 창의 Script Editor):
  1. 현재 작업을 보존한 뒤 File > New로 빈 장면을 준비합니다.
  2. Window > Script Editor를 엽니다.
  3. 다음 두 줄을 붙여넣고 Run을 누릅니다. 터미널 명령이 아닙니다.
       import runpy
       runpy.run_path("/home/robotis/workspaces/hx5_isaac/cyclo_lab/sg2_usd_investigation/scripts/open_sg2_in_existing.py")
  4. SG2 Manual Control 창에서 이동/STOP/그리퍼/Demo once를 조작합니다.
이 실행기는 SimulationApp을 새로 생성하지 않으며, 조작 창을 닫아도 기존 Isaac Sim은 종료하지 않습니다.
이미 조작 창이 보이면 중복 실행하지 않고 그 창을 사용합니다.
손목 추가 전 장면을 열어둔 경우 SG2 조작 창을 닫고, File > New 후 위 두 줄을 다시 실행합니다.
기존 비어 있지 않은 장면은 자동 교체하지 않습니다. 빈 장면을 먼저 준비하라는 오류를 출력합니다.

화면에서 직접 조작하기 (설치된 Isaac Sim 6.0.1-rc.7 GUI):
  /home/robotis/isaacsim/python.sh sg2_usd_investigation/scripts/manual_gui_601.py
짧은 직진/옆 이동/그리퍼 시연 후 조작 창을 열어두려면 --demo-once를 추가합니다.
GUI/GPU와 X 디스플레이 접근이 필요합니다. Docker 5.1 대신 로컬 6.0.1을 사용합니다.
공식 source/ 및 runtime/ 로봇 파일은 참조만 합니다. 바닥·모터·표시는 메모리의 새 stage에만 작성합니다.

조작 창: SG2 Manual Control - separate trial
  +X Forward / -X Back / +Y Left / -Y Right: 월드 X/Y 방향으로 계속 이동
  STOP: 바퀴 속도를 즉시 0으로 명령 (별도 로봇 기준 좌표가 아닌 월드 좌표)
  Speed: 다음 이동 버튼을 누를 때 적용할 속도 (m/s)
  Both grippers 슬라이더 또는 Grip 0 / Grip 0.8: 양손 마스터 관절 명령 (rad)
  Hand close-up: 왼손 확대. Home view: 현재 로봇 전체 보기
  Left wrist RGB / Right wrist RGB: 좌우 손목 카메라 영상 창 표시/숨김
  Follow ON/OFF: 주 화면이 이동하는 로봇을 따라가기
  CoM dot ON/OFF: 현재 질량·자세에서 계산한 무게중심의 빨간 점
  Demo once: 직진→정지→옆 이동→그리퍼0.8→그리퍼0의 짧은 시연
  Reset robot: 시뮬레이터와 관절을 초기 상태로 재설정
초록색 포인트는 실제 RTX LiDAR 출력이며, SG2 Head RGB와 Left/Right Wrist RGB 창은 각 장착 카메라 시점입니다.
손목 위치는 ROBOTIS URDF, optical 방향과 명목 FOV는 RealSense D405 자료 기준입니다.
실측 카메라 보정과 스테레오 깊이 오차는 재현하지 않습니다.
standalone manual_gui 실행에서는 조작 창을 닫으면 시험 프로세스가 종료됩니다.
기존 창용 open_sg2_in_existing 실행에서는 조작 창을 닫아도 Isaac Sim은 계속 켜져 있습니다.
